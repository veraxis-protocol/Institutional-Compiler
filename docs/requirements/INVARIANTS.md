# Core Invariants

- **I-01:** No executable control field without a source anchor or explicit institutionally admitted addition.
- **I-02:** No enforcement artifact from an interpretation state earlier than `admitted`.
- **I-03:** Unknown never serializes as grounded false.
- **I-04:** Missing authority, admission, required evidence, current version, or grounding facts never silently yields `ALLOW`.
- **I-05:** Candidate extraction confidence never substitutes for institutional admission.
- **I-06:** Every admission records reviewer identity, role, authority basis, scope, timestamp, and source/control versions.
- **I-07:** Every executable artifact binds compiler, schema, source, admission, and test versions.
- **I-08:** Target code is a projection; canonical institutional meaning resides in Institutional IR.
- **I-09:** Hosted and open implementations use the same semantic compiler core.
- **I-10:** Model unavailability or model change cannot alter already admitted controls.
- **I-11:** ZTL proves warrant only from admitted grounds; it does not establish source authority or interpret prose.
- **I-12:** VEIP preserves execution continuity; it does not create institutional meaning.
- **I-13:** Revoked, expired, superseded, or suspended authority cannot yield a current allow.
- **I-14:** Changes to sources or admitted meaning create new versions and impact records; never silent mutation.
- **I-15:** Every published runtime verdict is replayable to its exact control, admission, sources, warrant, inputs, and versions.
