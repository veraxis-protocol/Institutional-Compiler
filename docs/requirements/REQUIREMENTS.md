# Bootstrap Requirement Set

## Product

- **REQ-P-001:** Convert heterogeneous institutional documents into source-anchored candidate normative units.
- **REQ-P-002:** Expose ambiguity, conflict, missing authority, and missing runtime inputs.
- **REQ-P-003:** Record scoped institutional review and admission.
- **REQ-P-004:** Produce a target-independent Open Control Envelope.
- **REQ-P-005:** Compile admitted deterministic controls to Rego.
- **REQ-P-006:** Return ALLOW, DENY, or CANNOT with reason codes and lineage.
- **REQ-P-007:** Identify affected controls after source or authority changes.

## Repository and Lab

- **REQ-R-001:** Repository runs locally without the hosted Lab.
- **REQ-R-002:** Hosted Lab uses the same open semantic compiler core.
- **REQ-R-003:** Results disclose compiler/model/config versions and limitations.
- **REQ-R-004:** Public Lab enforces launch content restrictions before upload.

## Evidence

- **REQ-E-001:** Benchmark corpora and annotations are versioned and hashed.
- **REQ-E-002:** Held-out and contamination policies are explicit.
- **REQ-E-003:** Quality thresholds are frozen before held-out evaluation.
- **REQ-E-004:** Comparative claims name the exact baseline, corpus, metric, version, and result.
