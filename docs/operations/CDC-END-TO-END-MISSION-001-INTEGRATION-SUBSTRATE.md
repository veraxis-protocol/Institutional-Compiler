Status: NON-RESULT-BEARING PREPARATION

executing it. It consumes only admitted OIC controls and rejects raw-source

final report, findings summary, and transmittal letter. Every generated value is
labelled `SYNTHETIC_DRAFT_NOT_OFFICIAL` and carries the applicable provenance
chain.
