# OIC-Bench Preflight

This is the seven-day experimental subset, not the full OIC-Bench v0.1.

The preflight corpus must include at minimum:

- one primary procurement policy;
- one definitions or glossary source;
- one approval/delegation matrix;
- one amendment or superseding source;
- one conflicting or stale operating procedure;
- evidence requirements;
- an exception;
- one discretionary clause;
- transaction cases producing ALLOW, DENY, and CANNOT.

Before ingestion, every source must appear in `SOURCE_MANIFEST.csv` with rights, provenance, immutable hash, effective dates, and declared authority status.
